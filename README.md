# かぼちゃランタンぬりえ

かぼちゃランタン（ジャック・オー・ランタン）の線画に色を塗る、子ども向けのぬりえアプリです。怖くない、かわいいハロウィンの雰囲気にしています。

公開URL（予定）: https://altogrow-ir.github.io/halloween-lantern-nurie/

## 遊び方

- デザインを3つから選びます
  - ふつうの ランタン（三角の目とギザギザの口）
  - ねこ ランタン（ねこ耳とねこの顔）
  - わらい ランタン（まるい目とにっこり口）
- ランタンはSVGで描いています。塗れる部分は、かぼちゃ本体（5つのパーツ）、へた、目（左・右）、鼻、口、ほっぺ（左・右）、そら、おつきさま、おほしさま、じめん、ねこ耳（ねこランタンのみ）などです
- 下のパレットから色（10色）を選んで、塗りたい部分をタップするとその色になります。選んでいる色は「えらんだ いろ」に表示されます
- 🧽 けしゴムを選んでタップすると、その部分が未塗り（白）に戻ります
- 「ほぞんする」を押すと作品を保存でき、下の「さくひん いちらん」で小さなプレビュー付きで見られます。作品は「ひらく」で続きを塗ったり、「けす」で削除したりできます
- 「いまの デザインを ぜんぶ けす」は、現在のデザインだけを未塗りに戻します（誤タップしにくいよう、画面の一番下に離して置いています）
- ひらがな多めのやさしい日本語で、ボタンやパレットは大きくしています。スマホではランタンが画面幅いっぱいに大きく表示されます

## 記録

- 作品リスト（デザイン種別、リージョンごとの色、保存日時）と、保存した作品数・今までに保存した回数を `localStorage` のキー `halloween-lantern-nurie-save-v1` に保存します。保存した作品数は画面の上のほうに表示します
- 制作途中の状態（現在のデザインと、デザインごとの塗り色）も同じキーに自動保存するので、再読み込みしても消えません
- デザインごとに塗り状態は別々に保たれるので、デザインを切り替えても前のデザインの色は残ります
- サーバーは使わず、ブラウザ（端末内）だけで完結します

## 構成

- Vite + React 19 + TypeScript（ESM、npm）
- ルート：`index.html` / `vite.config.ts`（base は `"/halloween-lantern-nurie/"`）/ `tsconfig.json` / `package.json`
- 実装の中心：`src/App.tsx`（＋ `src/main.tsx`、`src/App.css`、`src/index.css`）
- 外部画像素材は使わず、SVG＋CSSで表現しています

## 開発・ビルド

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # tsc -b && vite build（dist/ に出力）
npm run preview  # ビルド結果の確認
```

## 公開

- ビルド成果物を `docs/` フォルダにコピーし、GitHub Pages の公開元を `main` ブランチの `/docs` に設定して公開します（ワークフロー方式は使いません）
